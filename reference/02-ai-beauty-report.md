# Veylumi AI 个性化美妆分析报告

## 产品目标

用户上传一张正面照片后，生成一份类似美容机构、形象顾问或美容学院教材的可视化报告：

```text
上传照片
  → AI 面部分析
  → 妆容风格适配
  → 肤色与个人色彩分析
  → 皮肤状态视觉观察
  → 适合妆容推荐
  → 教学图解与妆后效果
```

## 报告模块

### 1. AI 面容分析图

分析：

- 脸型
- 三庭五眼
- 肤色
- 冷暖皮倾向
- 五官比例
- 眼型、唇形等局部特征

推荐最终妆容方向：韩系裸妆、大地色眼影、奶茶色腮红、MLBB 唇色等。

建议版式：中心放原始肖像，周围放推荐面板，每个风格显示适配星级或分数。

### 2. 妆容风格适配图

候选风格：

- 大地系妆容
- 韩系裸妆
- 奶茶妆
- 纯欲妆
- 日杂妆
- 欧美浓颜妆

每种风格输出：

- 适配分数
- 推荐眼影颜色
- 推荐腮红颜色
- 推荐口红颜色

使用专业化妆色卡，并以美容顾问报告的形式呈现。

### 3. 肤色分析图

分析个人色彩季型：春、夏、秋、冬，并突出最匹配的季型。

输出：

- 推荐服装颜色
- 推荐口红色号方向
- 推荐腮红色号方向
- 推荐发色
- 推荐整体配色
- 可视化色板

### 4. 皮肤状态分析图

使用半透明面部叠加层、热力图或局部标注，观察：

- 水分
- 油脂
- 毛孔
- 敏感度
- 肤色均匀度
- 黑眼圈
- 法令纹
- 照片可见的肤质类型倾向：干皮、油皮、混合皮、中性皮

建议视觉风格：白色背景、医疗美容报告、专业美容机构可视化、9:16。

产品措辞应使用“照片条件下的视觉观察”或“初步倾向”，不要包装成医学检测。

### 5. 最终推荐妆容效果图

这是整个报告的核心结果，包含：

- 原始照片与妆后效果对比
- 适合的妆容风格
- 肤色与妆容色彩建议
- 眼妆、腮红、唇妆和轮廓重点
- 可执行的教学步骤
- 对应商品推荐

目标结果类似《AI 个形象诊断报告》，适用于美容机构、形象顾问和个人美妆课程。

## 推荐的产品数据结构

AI 生成的建议应与真实商品数据库连接，而不是让模型自由编造产品：

```text
产品部位
  → 功能标签
  → 色彩/色号
  → 适合肤质
  → 适合妆容风格
  → 价格区间
  → 购买链接
  → 平替商品
```
