# Veylumi V2 预留范围

V2 在 V1/MVP 阶段只做能力边界留档，不进入当前交付，不对用户承诺精确的人体测量、尺码或穿搭效果。

## 预留方向

- 人体信息建模：身高、体型比例、肩腰胯和服装偏好。
- 穿搭推荐：按场景、季节、预算、地区和可购买链接推荐服装与配饰。
- 妆容与穿搭联动：让妆容色调、发型、服装和配饰形成完整造型方案。
- 视觉演示：在明确标注“效果预览”的前提下，支持更高保真妆容/穿搭合成。
- 多人和非正脸输入：需要重新设计隐私、身份、脸部归因和错误提示，不直接复用 V1 规则。

## V2 不应提前实现的内容

- 不把脸型或体型分析包装成医学、审美或身份结论。
- 不在没有尺码表、库存和地区数据时承诺“适合购买”。
- 不默认保存人体或面部原图；仍需显式授权、最短保存周期和删除审计。
- 不把生成图片当成真实试穿或真实上脸效果。

## 进入 V2 的门槛

1. V1 分析完成率、有效反馈率和商品链接有效率达到 PRD 设定门槛。
2. 商品、色号、教程数据具备来源、更新时间和失效检测。
3. 真实视觉模型的授权、内容安全和跨中美部署方案完成评审。
4. 用户研究确认用户愿意为“完整造型”而非单次图片生成持续使用。
